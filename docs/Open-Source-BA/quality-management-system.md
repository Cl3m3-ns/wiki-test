# Quality Management System

## How can the open-source QMS documents from the AMPEL platform help me?
The QMS documents can never be adopted 1:1, as every in-house medical device software is unique and requires site-specific documentation. Use our technical documentation as a template or an example of what this complete documentation might look like. When [integrating the AMPEL platform as SOUP](practical-advice.md), the open-source QMS documents can be helpful in evaluating the quality and reliability of the SOUP.

## Do the QMS documents always match the software code version?

We make every effort to keep the versions synchronized. Nevertheless, we recommend checking whether a discrepancy currently exists. To do this, simply compare the version of the QMS documents with the release version. If you wish to use an older release version, you can download the corresponding QMS documentation via Git version control (==link==).

## Where can I get help with my site-specific QMS documentation?

We provide platform documentation, but do not offer custom consulting. If this is the first time your clinic is developing MDR-compliant in-house medical device software, we recommend engaging professional consultancy services. Make sure the provider has specific experience with "in-house medical devices" and "software." We have also summarized additional practical tips [in this article.](practical-advice.md)
